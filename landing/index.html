Travel & Tourism

Multilingual booking platforms for guides and agencies — date-based requests, quotes, payments and invoicing, a full two-tier admin, and SEO built in from the ground up.

Tibeb Travel

travel tourism booking

A multilingual booking site for an independent tour guide in Ethiopia — travellers pick their dates and request a private 14-day circuit, while a full admin manages requests, quotes and payments end-to-end.

  • Four locales (Hebrew, English, Amharic, French) with full RTL support and browser/geo language detection
  • Date-picker booking flow landing in a two-tier admin (owner + guide views) with live status and quotes
  • Automated client emails via Resend and Grow payment links, with auto-issued invoices
  • SEO-complete (hreflang, JSON-LD, dynamic OG) and deployed on Hetzner with nginx + PM2 behind Cloudflare

05 1 project + pipelines

Bioinformatics & Data pipelines

From raw sequencing data to actionable insight — reproducible pipelines and browser-native genomic tools, designed, implemented and deployed on-prem or cloud-native.

AriaDNA

bioinformatics genomics web app

A browser-native genomic viewer for sequences, alignments, phylogenetic trees and matrices — everything runs client-side, so data never leaves the user's machine.

  • Six viewers in one workspace: sequence/GenBank, alignment, tree, matrix, Sanger and variants/BLAST
  • iTOL-style phylogenetic trees (NJ, UPGMA, MST, GoeBURST) with metadata coloring and pie-node grouping
  • Fully client-side parsing and canvas rendering — no uploads, multi-document tabs, instant load
  • Deployed on a custom nginx stack at ariadna-bio.com with a marketing site and in-app docs
React Vite D3.js Zustand Canvas Nginx
